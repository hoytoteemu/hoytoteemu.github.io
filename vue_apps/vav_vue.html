VAV – Vue 3 Web Applications

VAV Verkkopalvelu
  • Developed two independent, highly interactive Vue 3 applications built as native Gutenberg blocks.
  • Created a dynamic apartment search app with real-time UI filtering, debounced REST API requests, and a wishlist functionality.
  • Engineered a bidirectional sync loop between Vue state, URL query parameters, and localStorage for shareable search filters.
  • Built a complex, 5-step rental application app handling multiple applicants, conditional fields, and real-time validation.
  • Designed a shared, composable module library (vue-modules) used by both applications to maximize code reuse.
  • Focus on accessibility (a11y) features, including focus traps, aria-invalid error highlighting, and dynamic heading focus during state changes.
