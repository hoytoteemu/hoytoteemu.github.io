Koululehtikone
  • A Vue 3 web application. App uses multiple custom REST APIs.
  • A media education tool for school classes to create and layout their own magazines.
  • Collects no personal data from students.
  • Students log in securely using unique, anonymous access codes that are automatically generated.
  • Automated cleanup process removes inactive temporary student accounts.
  • Custom layout engine detects text overflow in real-time as users type.
  • Generates print-ready A3 booklets or A4 PDFs directly within the browser.
  • Custom token-based lock mechanism prevents concurrent editing conflicts.
  • Drag-and-drop interface for ordering stories and calculating page numbers.
  • Strict security model with closed core API endpoints and ownership-based access control.
