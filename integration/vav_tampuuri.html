VAV – Tampuuri API Integration

VAV Verkkopalvelu
  • Developed a deep, bidirectional integration between WordPress and the Tampuuri API.
  • Built a three-layered architecture (Middle Layer, Endpoint Layer, HTTP Layer) for robust data synchronization and error handling.
  • Cron based automated background sync to pull building and apartment data into custom WordPress post types (CPTs).
  • Complex data mapping system that translates multi-step Vue frontend form data directly into Tampuuri-compatible JSON structures.
  • Created customized WP-CLI commands and a WordPress admin UI for monitoring and managing manual API synchronizations.
