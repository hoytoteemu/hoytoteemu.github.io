WooCommerce – Flodesk Newsletter Integration

Utuliini checkout page
  • A checkbox is added to the WooCommerce checkout page for customers to subscribe to the newsletter.
  • The customer subscription preference is saved to the order meta data.
  • After payment is complete, if the customer subscribed, their name and email are sent to Flodesk via the API and added to a specific segment.
  • API errors and responses are logged for troubleshooting.
