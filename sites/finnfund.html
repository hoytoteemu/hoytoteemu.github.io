Finnfund

Finnfund site
  • I was lead developper in this project.
  • Finnfund does impact investing in developing countries.
  • The site has an interresting vue app for Finnfunds investments.
  • My purpouse in this project was to make all of the vue apps for archives and single pages
  • The investments are imported using a CSV file.
  • The investment app features an interactive world map—users can click countries to filter and view investments specific to those locations.
  • Multiple filters allow users to refine the displayed investments by various criteria.
  • Users can export their filtered investment data as a CSV file for further analysis.
